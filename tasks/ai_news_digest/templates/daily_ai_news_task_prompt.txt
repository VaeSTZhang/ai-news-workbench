任务名称：每日 AI 与短剧趋势速览
执行时间：每天北京时间 11:00
总结范围：前一天

输出目录：
- global_ai：`tasks/ai_news_digest/news_reports/global_ai/daily/YYYY-MM/YYYY-MM-DD/`
- chinese_short_drama：`tasks/ai_news_digest/news_reports/chinese_short_drama/daily/YYYY-MM/YYYY-MM-DD/`

每类必须生成：`.docx` `.html` `sources.json` `task_log.txt`

数量标准：
- global_ai：不少于 10 条（可扩展到 15 条）
- chinese_short_drama：不少于 8 条有效内容

单条质量标准：
1. 标题（具体）
2. 发生了什么（2-4 句）
3. 为什么重要（1-3 句）
4. 对 ManJuFlow 的启发（1-3 句）
5. 来源（紧跟条目）

短剧补充规则：
- 榜单不足可写“趋势观察/延续观察/平台动向”，必须明确标注。
- 不得编造排名、热度值、播放量。
- 趋势观察至少 2 个来源支持。

禁止事项：
- 不生成 `.md` 新闻报告
- 不生成图片
- 不写本机绝对路径

生成后检查：
- daily 目录不为空
- global_ai>=10
- chinese_short_drama>=8

Git 常规提交默认允许（仅限项目根目录且通过敏感文件检查）：
`git status` `git add` `git commit` `git pull --rebase origin main` `git push origin main` `git remote -v` `git diff` `git log`
