AI News Digest HTML Style Guide (single-file inline CSS only)

1) Technical constraints
- Use a single HTML file with inline CSS.
- Do not use external CSS, JS, fonts, images, icon libraries, or CDN resources.
- Keep structure semantic and readable on desktop/mobile.

2) Required page sections
- Hero: report title, summarized date, track name, update date, report type.
- Summary: one-line summary, included item count, source count, quality status.
- Scope: short note clarifying this page includes only the current track content.
- News cards: one card per item.
- Footer: generated-by statement + public verifiable source statement.

3) Card field order (mandatory)
- 标题
- 日期 / 平台 / 公司
- 发生了什么
- 为什么重要
- 对 ManJuFlow 的启发
- 来源链接

4) Visual direction
- Neutral light background + centered container + paper cards.
- Subtle border, radius, shadow, spacing.
- Clear label hierarchy and readable line length.
- Source links visible at card bottom; do not move all sources to page end.

5) Theme distinction by track
- global_ai: restrained tech-blue accent.
- chinese_short_drama: restrained warm-content accent.
- Keep color contrast accessible and avoid over-design.

6) Low-signal day presentation
- Do NOT create "monitoring note" cards or fake news entries.
- If verifiable news is insufficient, the summary section should state this in natural language.
- The main news list should only contain real, verifiable news items.
- Do not write internal QA wording such as "主列表为空/整改版/见task_log/已剔除".

7) Prohibited content in news cards
- 禁止伪新闻条目：监测说明、方法论、采集策略、来源不足说明、双来源规则、模板规则、自动化说明、长期趋势空话。
- 禁止伪装话术："今日无重大新闻"、"公开榜单入口有限"、"建议持续关注"、"本期未发现足够新闻"。
- 禁止泛来源：不允许只用首页、频道页、搜索结果页、平台入口页作为正式来源。
- 每条新闻卡片必须是独立新闻/观察，必须有直接来源链接。

8) Source requirements
- Each news card must have specific, verifiable sources at the card bottom.
- Sources must be article pages, announcement pages, ranking pages, product release pages, regulatory document pages, or verifiable data pages.
- Homepage, channel pages, search result pages, or platform entry pages are NOT acceptable as primary sources.
- Comprehensive trend observations require at least 2 directly related sources.

9) Quality rules remain mandatory
- Daily: previous day only.
- Monthly: previous natural month only.
- No methodology/rules text as fake news entries.
- Each item must have directly supporting, publicly accessible sources.
- If 0 real verifiable items exist, do not generate formal HTML/DOCX reports; only generate task_log.txt.
