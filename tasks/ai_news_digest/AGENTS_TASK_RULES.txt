AI News Digest task rules (local scope)

1. Maintain task files only under `tasks/ai_news_digest/`.
2. Active output root is `tasks/ai_news_digest/news_reports/`.
3. Current active tracks are only `global_ai` and `chinese_short_drama`.
4. Both tracks must be reviewed and updated together in each remediation.
5. Daily command entry is `更新新闻` and must follow `RUNBOOK_UPDATE_NEWS.txt`.
6. Do not output markdown reports for this workflow.
7. Do not include machine-identifying local path data in public artifacts.

Hard quality rules:
A) Daily scope: previous day only. Monthly scope: previous natural month only.
B) Daily正文禁止方法论、采集规则、模板规则、安全规则类伪新闻。
C) 信息不足时允许低于目标条数，但必须采用正式读者说明，不得使用内部验收措辞。
D) Monthly de-dup is mandatory; same core event/trend cannot be split into padded entries.
E) `sources.json` fields required per record:
   id, category, title, url, publisher, published_date, accessed_date, used_in_section, reliability_note.
F) Every main-list item must have directly corresponding publicly accessible sources.
G) Run sensitive-content checks before commit.

Hard prohibition rules (must not appear as news entries):
H) 禁止伪新闻条目：监测说明、方法论、采集策略、来源不足说明、双来源规则、模板规则、自动化说明、长期趋势空话。
I) 禁止伪装话术："今日无重大新闻"、"公开榜单入口有限"、"建议持续关注"、"本期未发现足够新闻"。
J) 禁止泛来源：不允许只用首页、频道页、搜索结果页、平台入口页作为正式来源。
K) 信息不足处理：如果当天真实可核验新闻少于 3 条，不生成伪完整日报；主列表只放真实条目；摘要区说明信息不足；task_log.txt 详细记录。
L) 如果 0 条真实可核验内容，则不要生成正式 HTML/DOCX 报告，只生成 task_log.txt 记录。
